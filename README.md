# VapourTech Enterprise Website

A responsive, single-page marketing website concept for VapourTech Enterprise, using the **Arctic Voltage** visual direction: Voltage Cobalt `#2525F5`, Electric Lime `#C8FF00`, Thermal Orange `#FF5738`, Carbon Black `#11121A`, and Frost White `#F4F2EB`.

## Files
- `index.html` — page structure and SEO metadata
- `styles.css` — responsive styling and motion
- `script.js` — mobile navigation and enquiry-form preview behavior
- `favicon.svg` — custom VT-inspired favicon

## Before public launch
1. Confirm the company's approved logo and replace the temporary text-based VT mark if supplied.
2. Verify the exact service list, operating areas, phone number, email, WhatsApp number and business hours with the company.
3. Connect the enquiry form to a verified company inbox or WhatsApp endpoint. It currently does not transmit submissions.
4. Replace illustrative imagery with approved photos of actual installations and completed work.
5. Confirm all claims and add real testimonials only with permission.

## Local preview
Open `index.html` in a browser. The page uses Google Fonts and Unsplash-hosted illustrative photography.

## GitHub Pages
The site is a static website and can be published from the `main` branch, root (`/`).
